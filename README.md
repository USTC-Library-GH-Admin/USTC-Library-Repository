# website-testing

This is a repository to save and edit code for the Koha website! The benefits of Github are that it automatically saves each version of a file, even if we edit it, so we can always refer or revert to old code if necessary. Please feel free to explore this website, and add any discoveries about Github to the Readme file.

General Tutorials:

Creating a File:
1. On the top level of tabs, click "Create a new file"
2. Copy and paste your code
3. Scroll to the bottom, and name and file and provide a description
4. Select "Commit directly to the master branch." (It should be pre-selected)
5. Create the file!

Recommendations: 
-In "Title," specify whether the code is for the sandbox, or the live website.
-Create a file for each "type" of code for the website - for example, the Header HTML, Landing Page HTML, etc.

-----

Overwriting a File:

There are two ways of editing files - you can directly overwrite the file, or create a pull request, which is an alternate version of a file that doesn't change the original code. Since Github keeps backups of old versions of files, you don't have to worry about making a mistake that will last forever.

1. Go to the file you want to make an alternate version of
2. Click the pencil (Edit) button at the top of the file
3. Edit the code
4. At the bottom, fill in the name and description, and select "Commit directly to the master branch."
5. The file should be overwritten.

-----

Creating a Pull Request:

A pull request is a branch or alternate version of the code. Pull requests are intended for discussion, so the first page you see on a pull request is a discussion chain where users can comment on the code. This can be useful for making notes on what you changed in the code and why, and the pull request itself can be used if you want to experiment with different variations on the same idea, like layout editing.

1. Go to the file you want to make an alternate version of
2. Click the pencil (Edit) button at the top of the file
3. Edit the code
4. At the bottom, fill in the name and description, but this time, select "Create a new branch for this commit and start a pull request."
5. The branch should be created. When you decide on your changes, select "Merge pull request."

You can see an example in the Pull Requests tab, called "Pull Request Demo."

-----

Checking the Edit History of a File:

1. Click on a file
2. Click on the History tab at the top of the code
3. You can select the version of the file you'd like to see. Additions to the code are in green, and deleted lines are indicated in red.

-----

How to Make Folders:

1. Create or edit a file
2. Click on the title. At the start of the title, type in the name of the folder, then a /. You can keep doing this to create new folders as much as you like. Finish with the filename, without a / at the end.

Note: You can't create empty folders.
